## General
This is a project for my dotfiles. It will require downloading basic software, config files for zsh, keyd, ghostty, hyprland (rice), ect.
We shall build as little as possible on our own and rely instead on already existing tools where they exist and just "fill in the gaps".
It is in essence a rice for Hyprland and should also have a status bar.
It must install zsh plugins as well as applying p10k (powerlevel10k).
This should all be automated via a shell script so that the user (me) at most has to curl-run the script and then select what 'modules' or 'sections' they wish to install. We can assume archlinux, but might also consider separating non-compatible parts for reuse with other distros if the need should arise.

All explicitly installed pacman packages can be found in `pacman-packages.txt` and can be generated by `scripts/generate-pac-list.zsh`
in `src` there are config files which must be placed (downloaded/copied/linked) to their respective target directories.
For example all files in `src/keyd/` should be placed in `/etc/keyd`. If not otherwise specified a directory should be placed in `$XDG_CONFIG_HOME/<DIRNAME>/` a.k.a. `$HOME/.config/<DIRNAME>/` where `<DIRNAME>` is the name of the directory in `src`.

Note that I have provided soft links to the real files in my system for now, but it should probably be so that the user `git clone`'s the dotfiles and we link to the repository file in the file system, but I am not sure so please advice on the best way to handle this. It must either way be easy to push dotfiles to remote and also fetch the freshest updates across different systems on different machines. 

## Hyprland
The hyprland config must be split into several files due to inlegibility when they become too large. 
They should be split up into logical units such as `binds.lua`, `monitor.lua`, `defaults.lua` (for the user setting their preferred software), `layout.lua`, `animations.lua`, etc.

## Rice
The rice should contain a theme switcher which has themes related (color palette-wise) to popular color themes such as vim's: habamax, gruvbox, the tokyo night family, esmerald, etc.
Note that themes should be global across the desktop environment, thus changing backgrounds, terminal colors and themes in compatible programs and applications.
The rice should have a professional and cohesive look.

## Statusbar
The statusbar shall indicate which workspace is currently active. It should have a system clock (in the format of the user's locale by default but this must be settable by the user). It shall also have a pie chart-looking button indicating battery level if the system is a laptop
