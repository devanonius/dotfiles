# AUR packages, installed with yay after it is bootstrapped.
# Prefer prebuilt packages: list <name>-bin whenever the AUR has one
# (compiling is slow). The installer swaps in -bin variants for listed
# names and their AUR dependencies automatically, and warns about anything
# it still has to build. Check names with: dot packages check
oh-my-zsh-git        # Oh My Zsh, installed to /usr/share/oh-my-zsh
wayle-bin            # status bar, notifications, OSD, wallpaper
walker-bin           # launcher
# Walker's backend and the providers this setup uses. Not elephant-all-bin:

# long time. Add more providers from: yay -Ss elephant | grep -- -bin
elephant-bin                      # backend
elephant-desktopapplications-bin  # launch apps
elephant-providerlist-bin         # list of providers in Walker
elephant-runner-bin               # run commands
elephant-calc-bin                 # calculator
elephant-clipboard-bin            # clipboard history
elephant-menus-bin                # custom menus (theme picker, power menu)
elephant-symbols-bin              # symbols and emoji
elephant-unicode-bin              # unicode characters
elephant-files-bin                # file search
elephant-websearch-bin            # web search
python-pywal16       # theme engine (wal); maintained fork of pywal
