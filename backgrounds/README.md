# Wallpapers

One folder per theme id, e.g. `backgrounds/tokyonight-night/`, with jpg, png,
webp or gif files. `dot theme set` shows the first (alphabetically);
`dot background next` (SUPER+CTRL+SPACE) steps through them. A theme with no
folder gets a plain screen in its background color.

Commit only images you may share (check their license).
